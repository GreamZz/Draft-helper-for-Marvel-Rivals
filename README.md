# Draft-helper-for-Marvel-Rivals
Программа для подбора оптимального контр-пика.

Проект не готов, работает на коленке. Не советую запускать, вдруг ваш пк взорвется.

На данный момент программа подбирает персонажей исключительно по матрице контр пиков и фильтрам (летающие, хитскан и тд.). Без интерфейса, только в терминале.

## Базовые функции
Позволяет пользователю выбрать 6 персонажей для команды противника. Алгоритм анализирует команду, выявляет ее слабые и сильные стороны. 
**Всего в игре 53 персонажа, для каждого будет прописаны ключевые параметры для того чтобы алгоритм мог их анализировать, в них входят:**
- Роль персонажа в игре (Танк, Хилер, ДПС)
- 6 Персонажей, троих из которых контрит герой, а другие три уже контрят его самого.
- Локальная роль (Дайвер, ДПС-хилер, Ближник, Дальник, Летающий)
- Тип атаки (Hitscan, Projectile, Melee)

Также будет выводиться примерный процент победы. Для этого используется скреппер истории матчей, который создает датасет для обучения модели, модель и будет выводить шанс победы.
